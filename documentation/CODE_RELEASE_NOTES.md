# Code release notes

Version 1.0.0 packages the frozen analysis for public reproducibility. Repository copies of the formal R and Python scripts received path-only portability edits so that inputs can be placed in `data/` and generated files are written to the ignored `reproduction_output/` directory. The random seed, participant definitions, time points, program definitions, statistical methods, thresholds, tests, and scientific outputs were not changed.

The feasibility script is retained as a historical artifact. Formal reproduction begins with `phase1b_temporal_validation.R` and proceeds only after its prespecified correlation anchors pass.
