# Data and code availability

Processed expression data and metadata are publicly available from NCBI Gene Expression Omnibus under accessions GSE168760 and GSE206495. This repository contains the authors' analysis code, frozen program definitions, selected derived result tables, figure source data, and reproducibility documentation. GEO source data remain governed by NCBI GEO and the original studies' applicable terms. The MIT License applies only to the authors' original code.
